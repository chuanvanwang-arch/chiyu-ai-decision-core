# 叙事逻辑 · AI 原生决策智能平台介绍（3 页）

## 受众与场合
面向已看过《AI 原生销售管理平台》材料的业务/技术决策者。他们熟悉「业务痛点 → 解决方案 → 技术创新 → 业务价值」的讲法，
本组页面的任务是回答一个后续问题：**这套能力能不能从销售一个域，变成公司的平台能力？**

## 一句话主张
**普通平台管数据，本平台管裁决。** 把「判断过程」本身变成系统里可计算、可审计、可进化的对象 ——
客户买的不是软件，是决策能力本身，且这份能力随使用而升值。

## 逐页内容

### 01 · 平台架构：四层 + 一条证据管道
- 主视觉：四层架构图（左侧四层竖排卡片，右侧纵向证据管道 K→M→D）
- 四层要点
  - L3 应用与场景层：免代码门户、场景组合（客户不写代码，用受控声明组装）
  - L2 决策智能内核：知识 → 记忆 → 裁决 的单向证据管道（★最核心）
  - L1 智能体团队：多智能体编排、复盘智能体、反馈闭环回接
  - L0 底座：粒子契约、事件总线、审计链、统一存储（PG + 向量）
- 底部金句：**数据在系统里，判断也在系统里 —— 中间不再断开。**

### 02 · 主要功能：五件把「判断过程」变成资产的事
- ① 有依据的裁决：主链六步时序不可重排；链末硬闸门（红线命中不放行）；置信度只认同一口径，缺依据显式报缺
- ② 记得住的上下文：事件流 + 结论双轨；可寻址、可溯源、双时钟分离；完整性不达标就报缺，不静默补全
- ③ 一事实两视图：图谱视图看关系与因果，故事线视图看时序与证据演化；两视图交叉可复算
- ④ 越用越准：夜间复盘出方 → 影子重放 → 事务应用 → 次日报告 + 一键回滚；阈值放宽永不自动、红线命中挂起
- ⑤ 免代码生长：自然语言 → 受控 Schema → 渲染器（禁止直接出页面代码）；动作面分级守卫 + 审计链全程留痕
- 底部条：**内核零业务字面量 —— 换领域只换配置画像，不改内核。**

### 03 · 与原有系统 / 新增场景的关系
- 三段流：原有系统（销售 / 研发 / 供应链各自一套，经验不复用） → 抽取公共决策内核 → 新增场景复用
- 三条关系
  - ① 不替换：原系统继续承载业务语义与数据，平台只接管「判断过程」
  - ② 抽取反哺：内核不是从零设计，来自真实项目实证；抽取后反哺各系统
  - ③ 新增场景零改动：新行业 / 新域 = 一份配置画像（领域取值 + 红线目录 + 评分口径），不改内核一行代码
- 底部条：**平台自己也在长：新增智能体、沉淀技能、夜间自调参 —— 全部在护栏内跑。**
