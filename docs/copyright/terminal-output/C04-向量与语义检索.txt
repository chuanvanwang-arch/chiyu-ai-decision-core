==============================================================================
  功能演示 04　向量与语义检索
  本地离线向量推理、维度补齐与降级语义
==============================================================================

$ vector_info()  —— 推理后端自检
  backend               : cpu
  model_status          : onnx
  vector_dim            : 512
  last_error            : None
  hash_dim              : 384

$ vector_available(column_dim=384)  —— 通道可用性
  是否可用                  : True
  后端标识                  : cpu
  模型目录                  : None

$ vector_resolve(text, column_dim=384)  —— 句向量求解（返回 向量/档位/标签）
  输入文本                  : 客户要求本季度内完成交付并追加预算
  向量维度                  : None（通道未就绪）
  档位 tier               : None
  标签 tag                : dim_over_column:512>384（禁止截断；改用哈希并在 provider_info 暴露）
  档位常量                  : VTIER_VECTOR=vector / VTIER_FTS_VECTOR=fts+vector
  覆盖度下限                 : 0.8

$ hash_vector(text)  —— 确定性哈希签名向量（离线兜底通道）
  维度                    : 384
  非零维度                  : 33 / 384（SHA-256 字节映射有符号扰动，稀疏属预期）
  L2 范数                 : 1.0
  幂等性校验                 : 两次计算完全一致 = True
