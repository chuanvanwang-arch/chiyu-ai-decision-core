  常量 CONTRACT_VERSION   : 1.0.0

$ capability_status(name)  —— 单项能力档位查询
    capability_status('store') -> stable
    capability_status('decision') -> stable
    capability_status('memory') -> experimental
    注：未登记的能力名查询会快速失败（见下）
    capability_status('portal') -> KeyError: 'portal'

$ deprecations()  —— 弃用别名查询（先告警后移除的弃用政策）
  在册弃用别名 5 项：
    - TIER_FTS_VECTOR          -> VTIER_FTS_VECTOR
    - TIER_VECTOR              -> VTIER_VECTOR
    - TIER_FTS                 -> VTIER_FTS
    - TIER_NONE                -> VTIER_NONE
    - TIER_ORDER               -> VTIER_ORDER

$ require_capabilities({'store':'stable'})  —— 构建期版本钉与兼容断言
  断言通过：能力 'store' 档位满足 'stable'（无异常抛出）
