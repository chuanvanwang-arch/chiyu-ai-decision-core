## 五、口径说明（重要）

1. **源程序范围经权利人 2026-10-09 确认**：仅收 `packages/` 下四个在研包（kernel / decision / portal / cli）的主源码。
   已弃用的 `chiyu-host`（2026-09-26 并入企业侧 host）、测试代码、构建产物均不纳入申报。
2. **数字自洽**：申请表「源程序量」与交存材料正文行数采用同一口径（13,590 行），避免申报数与材料不符。
3. **能力状态如实披露**：记忆网（memory）相关能力处于实验态，未纳入本版本稳定承诺，功能说明中已单列声明。
4. **界面截图真实性**：全部截图取自真实运行环境。图形界面截图由浏览器实际操作门户产生（数据由底层契约与
   决策能力实时返回）；终端运行截图的内容为命令行入口与门面调用演示脚本的**真实标准输出**，
   原始文本留存于 `terminal-output/` 目录，可逐份比对。演示脚本仅调用软件对外公开门面，不含任何预置结果。
