本软件是青羽 AI 原生底座软件（ChiYu-Foundation）V1.0，是面向 AI 原生应用开发的公共能力底座，为上层业务项目提供契约、存储、检索、上下文、动作、决策与门户等公共能力，一次做成、多项目复用。软件采用严格的分层架构与受控消费面设计：内核只声明形态、不携带领域字面量，业务取值与执行由消费方注入；消费方仅通过官方门面访问能力，配合导入方向与门面覆盖的机械守卫，保证多项目接入时架构纯度不退化。

（1）契约与配置载体（L0）：以租户画像（TenantProfile）与红线规格（RedlineSpec）承载消费方的向量维度、知识谓词、红线事项目录等取值，内核只声明形态与约束；对外暴露公开门面版本与契约版本（API_VERSION / CONTRACT_VERSION），供消费方在构建期做版本钉与兼容性断言。

（2）粒子与本体管理（L1）：提供统一的业务实体模型（Particle）与规范化、词向量、嵌入补齐等写时处理钩子；本体图（OntologyGraph）以受控谓词维护实体间关系，配合回填通道完成历史数据的嵌入补全，形成可检索的业务事实底座。

（3）向量与语义检索（L1）：内置本地离线向量推理能力，基于 ONNX 运行时完成句向量计算，无需依赖重量级深度学习框架；向量经维度补齐与内容哈希处理后写入 PostgreSQL + pgvector 单一事实源，支持余弦相似度检索、覆盖度计算与回填计划生成，实现跨会话的语义召回。

（4）情境装配与降级召回（L1）：按分层情境模型（L1–L4）装配决策所需的上下文，提供三级降级召回语义与供需缺口检查（check_supply_demand），在历史先例不足或向量覆盖不全时按既定降级路径取数并留痕，避免静默返回空结果。

（5）图存储与关系视图（L1）：提供统一的图存储协议与内存、递归查询两种实现，支持受控谓词集校验、一跳出入边查询、多跳遍历（带深度上限与环检测，触及上限时显式标记截断）、关系图谱视图、时间线视图与决策回链查询；协议不暴露通用写方法与通用图算法，写边统一走受控入口，防止多源双写。

（6）决策脊柱（L2）：实现六阶段决策脊柱运行时，按「接收触发上下文 → 本体分级派生 → 八要素与九尺子评分 → 按外置权重加权聚合 → 红线硬判定与自主放行 → 决策落库」的固定顺序执行，并在构造期提供顺序校验，禁止以性能为由重排；评分子系统按九项评分量规（清晰性、准确性、精确性、相关性、深度、广度、逻辑性、重要性、公平性，各 0–4 分）对决策叙述打分，综合置信度只取评分比值来源，并支持八要素齐备性检查与置信度聚合；自主放行闸门以「红线命中即屏蔽，否则置信度达阈值（缺省 0.79）方放行」为完整判据；决策错误以结构化错误码（引擎故障 / 未知场景 / 维度不符 / 契约违背）抛出，便于调用方按码路由而非按文案匹配。

（7）审批治理与续跑（L2）：审批结论采用待定 / 通过 / 驳回三态模型，待定态决策可凭决策标识续跑并保持幂等；续跑遵循「冻结裁定」原则，只补落库阶段、不重算置信度、不重判红线、不改动任何裁定字段，且驳回为终态不得经续跑复活；红线命中强制改判为驳回并留审计痕迹，形成可审计的治理闭环。

（8）事件、审计与探针（L1）：提供事件总线驱动的能力联动、审计留痕，以及金丝雀探针（canary）用于接入期的连通性与落库自检，帮助消费方在正式接入前完成环境自证。

（9）门户运行时（L3）：支持自然语言到页面描述的解析与守卫（guard_nl_input），将页面描述渲染为可交互页面，并提供引导式导航与页面存储；不安装门户层时，底层契约与决策能力保持完整可用。

（10）插件与工作模式（L1）：提供插件注册表与能力槽位声明机制，内置终端、循环、子智能体、联网检索、团队协作、语音六类插件，并组合为标准、程序化工具调用、精简、创造四种工作模式；模式解析在未知或缺失时回落默认并留告警，不中断运行。

（11）模型接入与协议适配（L1）：提供分层的模型接入层（本地与云端端点预留）与 MCP 服务能力，含传输层接口契约与命名规范化，支持把底座能力以标准协议暴露给外部智能体与业务系统按需调用。

（12）命令行与运维工具（CLI）：提供决策执行、门户渲染、引导页生成、工作模式查询、包内自测、自进化开闸认证、受限命令壳等子命令，便于开发期调试与生产期自检。

（13）质量保证与守卫工具链：提供导入方向检查、门面覆盖检查、零残留检查、分发物与源码同步检查、能力清单生成等守卫脚本，均已接入持续校验流程；每个守卫要求先做判别力自证（删除判据后必须转红），防止"永远绿"的假门禁。

（14）版本化与兼容承诺：能力清单以机器可读方式登记并标注稳定 / 实验态档位；对外提供能力查询、能力状态查询与弃用别名查询接口；版本、能力档位与符号缺失在导入期即快速失败；变更遵循严格加法原则与先告警后移除的弃用政策，保证消费方升级不破。

说明：其中记忆网相关能力处于实验态（未经完整验收），不作为本版本对外承诺的稳定能力。
