## §1 赛道 E 任务拆解(映射到底座)

| 子任务 | 含义 | 底座复用点 |
|---|---|---|
| 融资方案匹配 | 按 SME 经营数据匹配贷款/信贷产品并给依据 | 粒子建模 + 本体图(`ontology/particle.py`,`graph.py`)+ 上下文检索(`context/retrieval.py`)+ 决策评分(`contract/decision.py`) |

## §2 技术方案骨架(基于 ChiYu 底座,零领域字面量)

### 2.1 分层架构(消费方视角,单向依赖内核)
```
L0 契约+基础设施   chiyu-kernel(contract/api 仅此二入口)
L1 金融粒子库      TenantProfile 注入:账户/流水/发票/贷款产品/现金流 粒子类型 + 取值
L2 决策脊柱        KMD 九尺子 → 融资匹配评分 / 现金流预警阈值 / 红线事项目录
L3 门户运行时      NL→Page 生成演示界面(可选装)
消费方 SME Agent   多智能体编排:匹配worker / 预警worker / 分析worker / 护栏守卫
```

### 2.2 数据模型(粒子系统,内核只声明形态)
- `ACCOUNT` / `LEDGER_FLOW` / `INVOICE` / `LOAN_PRODUCT` / `CASHFLOW_PROJECTION`
- 取值、知识谓词、红线事项目录**全部由 `TenantProfile` 注入**(`README.md:17` 分层铁律①),内核零金融字面量。

### 2.3 知识注入
- 金融产品目录、合规谓词、红线项 → `contract/profile.py` 注入;本体图写时向量化(`vector/onnx_runner.py` 离线、禁出网)。

### 2.4 决策与护栏
- 融资匹配:九尺子评分产出排序 + 依据文本(可解释)。
- 现金流预警:阈值由 knob 配置,命中即告警;**红线命中→挂起**(不自动放宽,`evolution/guard.py`)。
- 所有写操作经审计链(`audit/chain.py`)留痕 → 直接生成「安全自评报告 + 执行证据」。

### 2.5 执行闭环(满足 40% Task Completion)
- 多智能体编排(`orchestration/agent_registry.py`,`dispatch_cfg.py`)真实跑通三大功能;
- **非链上赛道**:执行证据 = 模拟 SME 账户沙箱运行日志 + 演示视频(不碰真实资金)。
