# chiyu-cli 终端运行平台实施计划（两版交付）

> 状态：P5 已批准（2026-09-24）。本文档为 brainstorming P6 产出，含 §A 生命契约。
> P0 回写预检：本设计无既有 `<doc>.feedback.json`，无历史缺口，闭环回写表为空（见 §闭环回写）。

## §0 背景与定位

AI 原生决策平台本体已完成（三包：chiyu-kernel / chiyu-decision / chiyu-portal，全平台 335 passed）。
但当前**无终端入口**：运行/验证/开发都依赖 `python -m pytest` 或手敲 `import`，对外部顾问不友好、对内也缺统一控制面板。

本任务新增**第四包 `packages/chiyu-cli`**，提供 `chiyu` 终端命令：脚本化子命令 + 交互壳，把三包公开门面（`*.api`）焊成可发现、可脚本化的驾驶舱。

**两版交付**（用户 2026-09-24 明确要求区分）：
- **全代码版（full）**：仓库源码即全部；`chiyu dev` 提供完整 Python REPL（可读源码）。
- **外部顾问版（external）**：受限于 NDA 的外部协作者；`chiyu shell` 为**受限命令壳**（禁 raw import），三兄弟包以 **pyc-only 轮子**分发（磁盘无 `.py` 源码）。

## §1 两版交付形态对照

| 维度 | 全代码版（full） | 外部顾问版（external） |
|---|---|---|
| 目标用户 | 内部开发 / 本人 | 签 NDA 的外部顾问 |
| `chiyu shell` | 受限命令壳（安全默认，两版一致） | 受限命令壳（同 full） |
| `chiyu dev` | 完整 Python REPL（预置 K/D/P 三门面） | **不打包该命令**（外部构建剔除） |
| 三兄弟包载体 | 仓库源码 `.py` | **pyc-only 轮子**（无 `.py`） |
| 泄露面 | 全开 | 仅公开门面行为 + 产物，无源码可读 |

> 统一安全默认：两版 `chiyu shell` 都走受限命令壳；完整 Python 能力只在 full 版的 `chiyu dev`。
> external 防护 = 「不打包 `dev` 命令」+「不交付 `.py`」，无需运行时沙箱 hack。

## §2 包结构与落点

新增 `packages/chiyu-cli/`（与 kernel/decision/portal 同级）：
```
packages/chiyu-cli/
  pyproject.toml          # pythonpath 含三兄弟 src；[project.scripts] chiyu = chiyu_cli.main:main
  src/chiyu_cli/
    __init__.py
    __main__.py           # 支持 python -m chiyu_cli
    main.py               # argparse 派发
    shell.py              # 受限命令壳（命令解析，非 eval）
    dev.py                # 完整 Python REPL（仅 full 版打包）
    commands/
      decide.py           # chiyu decide
      portal.py           # chiyu portal render
      evolution.py        # chiyu evolution readiness [--assert]
      selftest.py         # chiyu selftest [--package]
  tests/
    test_cli_dispatch.py  # --help / 子命令派发
    test_cli_shell.py     # 受限壳：白名单命令通过 / raw import 被拒
    test_cli_portal.py    # render 产出合法 HTML
    test_cli_evolution.py # readiness 打印 10 项
    test_cli_selftest.py  # 触发 pytest 且计数
```

`tools/build_external.py`：外部版构建脚本（见 §4），不属于 chiyu-cli 包，入 `tools/`。

## §3 子命令与 REPL

| 命令 | 作用 | 调用 |
|---|---|---|
| `chiyu decide --topic "<描述>" [--json]` | 跑决策脊柱/评分（确定性分支，不接真实 LLM） | `chiyu_decision.api` |
| `chiyu portal render --nl "<页面描述>" --out p.html` | NL→Schema→HTML 落盘（零 Web 服务即可看产物） | `nl_parser` + `render_page` |
| `chiyu evolution readiness [--assert]` | 打印 10 项 `CheckResult`；`--assert` 未全绿抛 `ChannelNotReadyError` | `assert_channel_may_open()` |
| `chiyu selftest [--package all\|kernel\|decision\|portal]` | 跑对应包 pytest | pytest 子进程 |
| `chiyu shell` | 受限命令壳（两版一致） | 命令解析循环 |
| `chiyu dev`（仅 full） | 完整 Python REPL，预置 `K/D/P` + `render()`/`readiness()` | `code.interact()` |

**受限命令壳（`shell.py`）实现要点**：
- 读取一行 → 按空格分词 → 首词匹配白名单 `{decide, render, readiness, selftest, help, exit}`。
- **非白名单即拒绝**（含任何 `import` / 赋值 / 函数调用语法），天然封死 `import chiyu_kernel` 逃逸。
- `render` 命令内部把 `--nl` 参数转给 `render_page`，输出到 `--out` 文件。
- **绝不**对用户输入执行 `eval()` / `exec()`。

**两种运行入口（零额外依赖）**：
- 零安装：`python -m chiyu_cli`（靠根 `conftest.py` / 各包 `pythonpath` 解析兄弟包）。
- 安装：`pip install -e packages/chiyu-cli` → 全局 `chiyu`。

## §4 外部版 pyc-only 轮子构建（真实可验证）

`tools/build_external.py` 流程：
1. 对 `chiyu-kernel / chiyu-decision / chiyu-portal / chiyu-cli` 各包 `compileall -b` → 平铺 `module.pyc`（同目录、非 `__pycache__`，CPython 支持 source-less 导入）。
2. 进 staging：只保留 `.pyc` + 运行必需数据资产（`manifest.json` / `tokenizer.json` / `config.json` 等非源码；**剔除所有 `.py`**）。
3. 按 wheel 规范打包 `.whl`（含 `.pyc`、`*.json`，不含 `.py`），并**不打包 `chiyu dev` 命令**（dev.py 不进 wheel）。
4. **验收（防假绿，必须真装真验）**：在**干净 venv** 里 `pip install` 该 wheel → `import chiyu_cli` 成功、`chiyu readiness` 跑通 → `find site-packages -path "*chiyu_*" -name "*.py"` **零命中**（四包名下无源码）→ 确认 external 防护成立。

> 注：`chiyu-cli` 自身为薄封装，其 `.pyc` 不含内核内部逻辑；暴露面仅公开门面行为。

## §5 范围边界（守纪律）

- ❌ 不接真实 LLM（决策走确定性分支，CLI 仅做能力演示 + 开发入口）。
- ❌ 不新增粒子类型 / 不改业务域模型（守 §10 硬约束）。
- ❌ 不污染内核（CLI 仅消费 `chiyu_*.api` 门面，与既有分层铁律一致）。
- ❌ 不补 `page.css` / 不建 Web 服务（终端产物即够用）。
- ❌ external 版不外泄源码（§4 机制保证）。

**第 2 层 · 自动化回归**

- 全平台 `pytest packages` 仍 **335 passed** 不回退（CLI 包接入无回归）。

**第 3 层 · 外部版专属验收**
- 干净 venv 装 wheel 后，四包 `*.py` 零命中 + `chiyu readiness` 跑通（§4.4）。
