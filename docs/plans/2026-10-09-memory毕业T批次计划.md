## 0. 现状核实（全部源码级实读，非印象）

memory 在内核实际有**两条互不相连的支线**，这是毕业工作的全部对象：

| 支线 | 落点 | 写路径 | 读路径 | 状态 |
|---|---|---|---|---|
| **① 记忆网（决策回链图边）** | `persist/__init__.py:127 write_decision_memory_net` 写 7 条 `MEMORY_PREDICATES` 边 | **已接** `PgVectorStorePersister.persist()`(:260) → 真 PG `graph_edge` 表 | `graph/__init__.py` `PgCteGraphStore` 只读派生视图（`decision_backlinks`/`relation_view`），但 **`run_spine` 不调用** | 写通、读有视图、决策时不消费 |
| **② 双轨 LOG/NOTE 运行时** | `persist/memory_tracks.py`（`InMemoryMemoryLog`/`InMemoryNoteStore` + `distill` 四闸 + `PRESCRIBABLE_PREDICATES` 白名单） | **无任何调用方**（孤儿） | **无任何读取方**（孤儿） | 仅内存参考实现，未接 PG、未接 run_spine |

**根因（为何还不是"基础能力"）**：
1. `run_spine`（`decision/spine.py:44`）只跑 S1→S5，**决策过程中从不读任何记忆**——记忆网边写了、双轨也蒸馏了，但决策时"写了不读 = 没用"（这是 `memory` 不能毕业的最大单点缺口）。
2. 双轨运行时（`memory_tracks.py`）**完全孤儿**：无写入触发、无 PG 落地、无读取消费（maturity-blueprint.md:116 称其为"唯一真缺口 → WS2"）。
3. 召回机制（`context/retrieval.py:128 degraded_recall`）是**纯函数**， caller 必须自带 `pool`；**没有任何代码把记忆系统喂给它**。
4. 全部测试 `test_memory_tracks.py` 用 `InMemory*`/FakeStore，**无真库往返**（违反蓝图 §3 反假绿要求）。
5. `version.py:96 ("memory","experimental")` + `api.py:425 MEMORY_EXPERIMENTAL=True` 仍在位。

**已具备、无需重做**（避免重复造轮子）：
- `write_decision_memory_net`（记忆网 canonical writer，受 B 闸 + F 闭环）✓
- `PgCteGraphStore` 纯 PG CTE 只读视图（AGE 等价，零扩展）✓
- `degraded_recall` 三级降级召回 + `to_supply_layer` ✓
- `distill` 四闸 + `PRESCRIBABLE_PREDICATES` 白名单 ✓
- `contract/memory.py` L0 契约（`MEMORY_KINDS`/`MEMORY_ADDRESS_KEYS`，铁律"不建新表"）✓

## 1. 设计决策（执行前锁定的边界，避免中途返工）

- **D1 — PG 落库映射**：双轨存储**复用既有 `event` / `particle` 表，零新 DDL**（守 H 单源纪律 + `contract/memory.py:3` 铁律 + `memory_tracks.py:16-18` 零建表铁则）。
  - `PgMemoryLogStore.append` → `INSERT event(event_type='memory_log', payload 携 kind/transient/explicit/source_decision_id)`；
  - `PgNoteStore.upsert` → `upsert particle(type='memory', layer='L2')` + `content_hash` 幂等（与 `PgVectorStorePersister` 同表同事务）。
  - ⚠️ 蓝图 :48 原文写"memory_log/notes 同源事务"——该措辞被 L0 契约与 memory_tracks docstring 的"reuse event/particle"决策**取代**，本计划按后者落地（不新建 `memory_log`/`notes` 表）。
- **D2 — run_spine 注入范式**：新增**可选** `memory_recaller: Optional[Callable[[Mapping], Mapping]]` 形参，在 S1_context 之后、S2_score 之前注入召回供给侧；与既有 `context_factory`(:52) 对称，**默认 None = 零行为变更**（向后兼容，预览/测试不受影响）。
- **D3 — 单源纪律**：记忆写路径仅三条且唯一事实源 = `write_decision_memory_net`（记忆网）+ `PgMemoryLogStore/PgNoteStore`（双轨）+ `OntologyGraph.link`（本体）。禁任何模块直写 `graph_edge`/`event`/`particle` 绕过上述 writer（T44 加守卫）。
- **D4 — 生产库禁忌**：E2E 仅跑 `chiyu_test` 便携 PG（`postgresql://chiyu@127.0.0.1:5432/chiyu_test`）；严禁指向 `81.70.184.198`（FORBIDDEN_HOSTS 守卫），与既有纪律一致。
- **D5 — T 编号撞号风险**：本计划用 **T40–T44** 草案区间；执行前**必须** `git status`/`git log` 核验最新 T 号（多会话并发曾撞号），按实际号提交，单行 `-m` 前缀 `T<n>:`，尾部附实测计数；禁 `git add -A`、显式路径 add、零 remote、禁 DELETE。

## 2. T40 — 双轨记忆存储 PG 化（PG 落库）【基础，最先可执行】

**目标**：把 `memory_tracks.py` 的 Protocol 落到真 PG，使"写"在落库态可持久、可被后续召回读取。

- **T40a 文件变更**：
  - 新增 `packages/chiyu-kernel/src/chiyu_kernel/persist/pg_memory_stores.py`：
    - `PgMemoryLogStore(MemoryLogStore)`：`append(entry)` → `store.execute(INSERT event ...)`；`iter_all()` → `SELECT` event_type='memory_log' 还原 `MemoryLogEntry`（含 transient/explicit/source_decision_id）；**协议形状不含 update/delete**（append-only 由 Protocol 保证）。
    - `PgNoteStore(NoteStore)`：`upsert(note)` → `store.upsert_particle(type='memory', layer='L2', ...)` + `content_hash` 幂等（同 `PgVectorStorePersister._skip_idempotency` 范式）；`get(key)` → 读回。
  - `persist/__init__.py` 导出 `PgMemoryLogStore`/`PgNoteStore`。
  - `api.py` sanctioned 面补导出（`MEMORY_EXPERIMENTAL` 旁的 memory 区块）。
- **T40b 验收**：新增 `packages/chiyu-kernel/tests/test_pg_memory_stores.py`（**`@pytest.mark.pg`**，chiyu_test）：
  - append→iter_all 往返一致；upsert `content_hash` 幂等（同内容二次 = False）；append-only 无 update/delete 通道（reuse `test_memory_tracks.py:101` 形状守卫）。
  - **变异自证 2 路转红**：① 删 `PgNoteStore` 幂等分支 → 同 content_hash 重复 upsert 返回 True（伪变更）即红；② 删 `PgMemoryLogStore.append` 落库 → `iter_all` 取不到即红。
- **T40c 组合回归**：`make test` 全绿 + `make lint` 门面覆盖 0 + §13 零残留 0。

## 3. T41 — 召回接入 run_spine（召回接入）

**目标**：打通"写了能读"——决策时把记忆网回链 + 双轨 notes 召回并注入 context。

- **T41a 文件变更**：
  - 新增 `packages/chiyu-kernel/src/chiyu_kernel/context/recall_memory.py`：
    - `recall_precedents(query_terms, *, query_vector=None, store, top_k=10) -> RetrievalResult`：
      - 源① 记忆网：`graph_store.decision_backlinks(decision_id)` / `relation_view` 取 `REFERENCED_PRECEDENT`/`ESTABLISHES_FRAME` 邻域 → 构建 pool 行；
      - 源② 双轨 notes：`PgNoteStore` 全量 `get` → 构建 pool 行（text=content, vector=None 降级）；

  - `decision/spine.py:44 run_spine` 新增可选形参 `memory_recaller: Optional[Callable[[Mapping], Mapping]] = None`；在 S1_context(:77) 之后、S2_score(:84) 之前：`if memory_recaller is not None: context = memory_recaller(context)`（与 context_factory 对称）。
- **T41b 验收**：新增 `packages/chiyu-decision/src/chiyu_decision/tests/test_spine_recall_injection.py`：
  - 注入的 precedent 进入 context 且被 S2 读取（断言 context 含 `supply` 层 precedent 键）；
  - **变异自证 2 路转红**：① 删 `memory_recaller` 调用 → context 无 precedent 即红；② 删注入写回 → S2 不读即红。
  - 向后兼容：`memory_recaller=None`（默认）时行为与现状字节一致（既有 test_spine_* 全绿）。
- **T41c 组合回归**：同上三件套。

## 4. T42 — 分层检索 / RRF fuse（检索/fuse）

**目标**：多源（记忆网图 / 双轨 notes / 向量）互补召回，RRF 融合提升覆盖率与排序质量。

- **T42a 文件变更**：
  - 新增 `packages/chiyu-kernel/src/chiyu_kernel/context/fuse.py`：`rrf_fuse(results: Sequence[RetrievalResult], *, k=60) -> RetrievalResult`，实现 Reciprocal Rank Fusion（`score_i = Σ 1/(k+rank_i)`），合并多源多档；保留各源 `evidence` 留痕。
  - `recall_memory.recall_precedents` 升级：分别产出 graph 源 / notes 源 / vector 源 `RetrievalResult` → `rrf_fuse` 合并；fuse 空源时**回退单源** `degraded_recall`（降级留痕，不抛）。
- **T42b 验收**：新增 `packages/chiyu-kernel/tests/test_fuse.py`：
  - 多源互补提升召回覆盖率（graph 源命中的项 notes 源未覆盖时仍进结果）；
  - **变异自证 2 路转红**：① 删 RRF 归一 → 并列项顺序错乱（同一 query 两次结果序不一致）即红；② 删单源回退 → fuse 遇空源即红。
- **T42c 组合回归**：同上三件套。

## 5. T43 — 真库 E2E 全链路（真库 E2E）

**目标**：在真 PG 跑通"写→读→注入决策"闭环，并附反假绿探针（蓝图 §3），证明记忆**真被用**而非"表有行即判通"。

- **T43a 文件变更**：新增 `packages/chiyu-kernel/tests/test_memory_e2e.py`（**`@pytest.mark.pg`**，chiyu_test）：
  - 链路：`PgVectorStorePersister.persist(... references=...)` 写记忆网 PG → `recall_precedents` 读回链+notes → `rrf_fuse` → `run_spine(memory_recaller=...)` 注入决策 → 断言决策 context 含该 precedent（"写了真被读"）。
- **T43b 反假绿探针（变异自证 3 路，任一失效即红）**：
  1. 删记忆网写边（`write_decision_memory_net` 短路）→ `recall` 取不到 precedent 即红；
  2. 删 recall 注入（`run_spine` 不调 `memory_recaller`）→ 决策 context 无 precedent 即红；
  3. 删 `content_hash` 幂等 → notes 重复落库（伪变更）即红。
- **T43c 工程**：Makefile `test` 组合显式含 `pytest -m "pg"` 或 `$(PG_TESTS)` 变量（可配置）；CI 不依赖生产（FORBIDDEN_HOSTS 守卫复用既有 `verify-release-source` 范式）。
- **T43d 组合回归**：`make test` 全绿（pg 用例随 `make test` 跑，或文档化需 `make test-pg` 单独触发，二选一在 T43c 定）。
