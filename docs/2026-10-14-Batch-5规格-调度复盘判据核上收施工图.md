# Batch-5 规格：调度复盘判据核上收施工图（#9 定时调度 + #11 零 LLM 夜报）

> 来源：两页分析 §三 候选 #9/#11（Batch-4 回函 T108 §五 排期）。范式与前批一致。
> IO 边界：定时器注册/setTimeout、DB 查最新 run_at、报告落盘/落库——留消费方；上收纯函数判决核 + 段隔离结构保证 + 零 LLM 渲染核。

## 一、上收清单（CRM 锚点为真值）

### scheduler_core（来源 scheduler/timers.js）
1. **next_run_at**（:185-190）：每日时点参数化（`RETRO_HOUR_DEFAULT=2` 是运维调度配置**非业务阈值**）；今日时点已过 → 顺延次日。
2. **catchup_verdict**（:199-207 判决核纯化）：`last_run_at` 距今 >24h → 补跑（stale）；<24h → fresh（天然限流，重启再频繁也不重跑）；距下次时点 <30min → near_schedule（护栏①：交给定时防补跑与定时双跑）。IO（查最新 run_at）留消费方；探测失败必须留痕（:215 禁裸 catch）→ reason 闭集 {fresh, stale, near_schedule, error}。
3. **run_batch_once 段隔离范式**（:141-182）：N 段 callable 注入，**每段独立 catch 互不传染**（复盘 LLM 失败不拖垮收口/体检）+ 每段失败必留痕（recordFailure 注入）+ 报告生成段独立兜底 catch。结构保证收为 `run_segments`（零域值零 DB，callable 全注入）。

### nightly_report（来源 report/nightlyReport.js）
4. **collect_segments**（:27-41）：三段归一化容错——任一段 null → 空结构，防渲染崩；param.items 贯穿（九尺子明细此前被丢弃的修复随语义上收）。
5. **extract_retro_metrics**（:57-77）：**双形态兼容**（实时形态 vs 落库回读持久化形态）——summary.* 为权威聚合、clusters 为明细、任一缺失回退顶层字段；drift=max(0,total-ok)；failReasons = llm_used===false 或 confidence<0.7 的簇；总数统一取「分析簇数」。
6. **render_nightly_markdown**（:80-147）：**零额外 LLM** 纯模板渲染（复盘段归因由消费方 LLM 产出，本报告只汇总不二次调用）；fmt_patch 处方文案（from→to 或 target→label）；**漂移口径修复**：drift>0 但无自动建议值时显示「需人工研判」而非误显示「全部健康」（:122-128）；九尺子参数快照段（rubric 前缀过滤，rubric 是基座概念非域值）。
7. **aggregate_report_metrics**（:161-170 纯化）：totalTasks/healthy/drift/patchesCount 聚合公式（drift 不含 insufficient——CRM 口径：rErrors 计入 drift、insufficient 只计入 total 与失败行）。

## 二、契约与登记

- `contract/scheduler.py`：RETRO_HOUR_DEFAULT=2 / CATCHUP_MAX_AGE_HOURS=24 / CATCHUP_NEAR_SCHEDULE_MS=1_800_000 / CATCHUP_REASONS(fresh,stale,near_schedule,error) / SEGMENT_ISOLATION_INVARIANTS(段失败隔离互不传染、失败必留痕禁裸 catch、报告段独立兜底) / SchedulerError。
- `contract/nightly_report.py`：REPORT_SEGMENTS(retro,routing,param) / RETRO_METRIC_FIELDS / FAIL_CONFIDENCE_THRESHOLD_DEFAULT=0.7（**D3 同源登记**：CRM 语境缺省、消费方可注入、勿与基座 0.79 互替）/ RUBRIC_ITEM_PREFIX="rubric"（基座概念）/ REPORT_INVARIANTS(零额外 LLM、null 段容错、双形态 summary 权威、drift 无建议不误报全部健康) / NightlyReportError。
