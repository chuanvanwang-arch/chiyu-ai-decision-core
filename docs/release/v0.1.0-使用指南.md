# foundation v0.1.0 使用指南

> 面向消费方（APS / enterprise / CRM）接入工程师。接口全集见同目录《接口参考》（机械生成）；
> 本指南覆盖**从安装到决策落库**的最短可用路径与关键纪律。

## 1. 安装与启动自检

```bash
# 双 wheel（推荐接法 H3）：kernel 与 decision 各自独立，按授权择一/组合安装
pip install chiyu_kernel-0.1.0-py3-none-any.whl
pip install chiyu_decision-0.1.0-py3-none-any.whl
# 离线向量后端（可选）：需先本机生成模型 —— python tools/export_bge_onnx.py
pip install "chiyu_kernel[cpu]"
```

```python
# ⛔ 启动即自检（G5 范式）：版本断言 + 能力闸，替代 hasattr 嗅探
from chiyu_kernel import api, require_capabilities

assert api.__version__ == "0.1.0"
require_capabilities(["decision", "persist", "approval", "store", "contract", "canary"])
# 未登记 / 状态不符 → RuntimeError 一次性列全（含 experimental 哨兵写法见 versioning 文档 §6）
```

## 2. 十分钟决策回路（最小可运行）

```python
from chiyu_kernel.api import profile_from_dict, PgVectorStorePersister
from chiyu_kernel.approval import RedlinePriorityGate          # 红线优先审批闸（WS3）
from chiyu_decision.api import run_spine, EIGHT_ELEMENTS, RUBRIC_KEYS

# ① 领域注入（WS6 关键石）：粒子/动作/场景由消费方注入，内核零领域字面量
profile = profile_from_dict({
    "tenant": "acme-auto",
    "particle_types": {"customer": {"layer": "L1", "serves_dims": ["decision_history"]}},
    "actions": {"follow_up": {"particle_type": "customer", "effects": [...]}},
    "predicates": {"EVALUATED": {...}},
    # 场景受控边：predicate 必须在 profile.predicates 内，否则构造期 fail-fast
    "scenario": {"controlled_edges": [{"from": "customer", "predicate": "EVALUATED",
                                        "to": "customer"}]},
})

# ② 决策（S1–S4 评分/八要素/红线/自主裁量，S5 落库）
result = run_spine(
    context={"text": "普通事项", "decision_id": "d-001"},
    profile=profile,
    rubric_scores={k: 4.0 for k in RUBRIC_KEYS},
    elements={e: "x" for e in EIGHT_ELEMENTS},
    redline_items=(),                       # 红线目录由消费方注入
    approval_gate=RedlinePriorityGate(),    # 红线命中即否决，高置信度不豁免
    persister=lambda r: persister.persist(r, subject_id="subj-1"),
)
# result.autonomous / result.pending / result.approval_rejected / result.persisted
```

## 3. 三种裁定终态与落库语义（B3 方案 Z）

| `SpineResult` 状态 | 语义 | 落库 | 审计事件 |
|---|---|---|---|
| 自主通过 | `autonomous=True, persisted=True` | 正常落 | — |
| **PENDING** | 闸裁需人工（`pending=True, persisted=False`） | **不落正边** | `approval_pending` |
| **REJECTED** | 红线命中强制改判（闸失职裁 PENDING 也会被脊柱改判） | 不落 | `approval_rejected` |

**PENDING 续跑（G3 `resume_spine`）**：

```python
from chiyu_decision.api import resume_spine

# 审批人批准后（贵方异步编排），只补 S5——不重跑 S1–S4、不重算置信度、不重判红线
resume_spine(result, persister=persist_fn, audit_sink=audit_fn,
             approval_ref="审批单号-12345")
# ⛔ REJECTED 是终态：对非 PENDING 结果 resume 抛 ValueError（红线硬拒不得复活）
#   若需按新红线目录重评：取消原决策、重新 run_spine —— resume 语义即"不重评"
```

## 4. 落库与存储（零建表铁则）

- 决策**不单独开表**：event（`event_type="decision"`）+ 同库 upsert particle（`type="decision"`）；
- 记忆网：7 条 MEMORY_PREDICATES canonical 边经 `write_decision_memory_net` 写入，写入前过
  `judge_worthiness`（凭证硬拒：红线命中不建正向先例边；瞬态噪声）；
- 双轨记忆运行时（B 专利）：`MemoryLogStore`（append-only，协议无 update/delete）+ `NoteStore`
  （content_hash 幂等 upsert）+ `distill()` 周期蒸馏（显式优先 → 价值视界，闸序即纪律）；
- 连接：`get_dsn` / `connect(connect_factory=...)` / `shared(connect_factory=...)`（驱动可注入，
  psycopg3 消费方同理）；`execute` 只写返回 None，读用 `execute_fetch`（`@overload` 单/多行可分）；
- ⛔ DSN 口令仅运行态注入，测试/探针严禁指向生产实例（isolation guard 库内拦截）。

## 8. 接入纪律（违反即失去兼容性保护）

1. **只 import sanctioned 面**：`chiyu_kernel.api` / `chiyu_kernel.contract` / `chiyu_kernel.approval` /
   `chiyu_decision.api` / `chiyu_portal.api`——内部路径不受 semver 保护；
2. 撞名符号（`register_scenario` / `Particle` 等）见撞名清单，建议全限定引用；
3. 版本断言用 `api_version()` + `require_capabilities`，禁止 hasattr 嗅探；
4. 弃用别名（`TIER_*`）会在下一版移除——升级前跑一遍 DeprecationWarning 扫描。

## 9. 常见问题

| 症状 | 原因与处置 |
|---|---|
| `RuntimeError: 未登记能力 / 状态不符` | `capabilities()` 对照《接口参考》头部键清单；experimental 项见 versioning §6 哨兵写法 |
| 离线向量 4 例测试失败 | ONNX 模型未生成：`python tools/export_bge_onnx.py`（README 已注明） |
| `inject_domain` 报"该边永远无法建立" | 场景 `controlled_edges` 的 predicate/from/to 不在 profile 内——构造期 fail-fast 是**设计行为** |
| resume 抛 ValueError | 对 REJECTED/已持久化结果续跑——REJECTED 终态不可复活 |
