## 三、域值边界（每项铁律）

- **RBAC**：角色别名表、权限矩阵内容、租户档位（SYSTEM_LEVEL/TENANT_LEVEL 角色清单）⇒ 消费方注入；foundation 只收判定算法 + fail-closed 语义。
- **standing_credential**：DB 表、租户隔离列、trace 事件名 ⇒ 消费方；foundation 只收 coverage/熔断/扫荡判决纯函数。
- **approval_engine**：金额档位阈值、角色链配置 ⇒ 消费方配置；foundation 只收 tier 解析算法 + 聚合语义 + 空审批人 fail-closed。
- **two_phase_token**：secret 管理、nonce 存储、过期时长默认值 ⇒ 消费方；foundation 只收编解码/验签/过期/一次性判定。
- **attribution**：七态**词汇**（域无关故障分类）上迁；edge spec、场景 required_dims、粒子三检 ⇒ 消费方注入。
- **audit_4q**：四问判据算法 + 口径常量（Q1_MIN_SUPPLIED_DIMS 等）上迁；图/溯源/冲突数据 ⇒ 消费方注入。
- **ab_experiment**：judge 阈值默认值入契约（可配）；场景/轨道/黑名单 ⇒ 消费方。

## 四、验收闸（每子批同既有纪律）

1. 契约 L0：零 import os/open/第三方；域字面量守卫零违反。
2. 机制纯函数：grading/判决类禁 IO（除明确 IO 边界模块）。
3. 双面 re-export：contract/__init__.py + api.py 同对象（`is` 锚）。
4. 登记三项：version.py CAPABILITIES + test LAYERS + capability-manifest.json + Makefile lint 层清单 + contract/manifest.json 重生成。
5. 守卫测试：每能力含 parity 锚点（CRM 锚点 file:line 对拍形态）+ 变异自证着力点。
6. 组合全量回归（六路径实跑）+ 退出码判据禁管道。
7. 提交：T 前缀单行 -m + 实测计数，显式路径禁 -A。
